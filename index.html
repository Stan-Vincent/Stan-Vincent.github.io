HChat 分布式即时通讯

基于 Qt 与 C++ 的分布式 IM 系统（C/S 架构）：Qt 6 客户端 + Boost.Beast HTTP 网关 + gRPC 分服协调 + 多台 Asio TCP 聊天服 + Redis/MySQL。支持私聊群聊、大文件流式上传、断线重连与断点续传。
